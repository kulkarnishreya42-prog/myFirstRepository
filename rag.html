The complete mental model

Remember RAG as two major pipelines: Indexing prepares knowledge, while Retrieval + Generation happens when a user asks a question.

📄 Documents → ✂️ Chunking → 🔢 Embeddings → 🗄️ Vector DB
❓ User Query → 🔢 Query Embedding → 🔍 Similarity Search → 🏆 Top-K Chunks → 🧠 LLM → 💬 Answer
